# README.md 编辑

## 流程

1. 通读仓库与现有 README，标出过期和缺失的节；选填节一次性问询用户
2. 按模板只改过期和缺失的节，其余原样保留；无 README 时按模板生成
3. 模板外的已有节保留；疑似冗余或混入 AI 约束的内容只向用户指出，不自行删改
4. 排版遵循 `markdown-editor`，对照验收清单自检后落盘

## 模板

```markdown

# 仓库名

（必填）简介，一句话说清本仓库存什么、承接什么协作。

## quick-start（必填）

给新成员的最短上手路径，有序列表，每步一个链接。

## 仓库结构（必填）

简单树，不全部展开，只列关键文件与文件夹并标注职能。`.agent/` 只列一行，不展开内部。

## 待办与路线（选填）

仓库有公开任务清单才写，链过去，不复述条目。

```

## 验收清单

- [ ] 现有 README 已通读，改动范围与本次变更对得上；无 README 时按模板生成
- [ ] 简介、quick-start、仓库结构齐全，选填节已问询用户
- [ ] 落盘稿中无模板说明行与示例残留
- [ ] 仓库结构与实际目录一致，`.agent/` 未展开
- [ ] 内部链接指向已存在的文件
- [ ] 未把其他文件正文抄进 README
- [ ] 未重复规定 Markdown 排版格式
- [ ] 全文小于 150 行
